Point & Shoot is a fully open-source pro camera app for Android 9+ (API 28+).

Built for shooters who want predictable Camera2 behavior, RAW-first workflows, and honest capability gating across devices — not a one-size-fits-all OEM clone.

<b>Fleet-first correctness</b>
• On-device capability matrix and parity tooling
• Controls hide when the hardware cannot deliver (no fake toggles)
• Primary USB validation lane: OnePlus 12 (CPH2583)

<b>Capture</b>
• DNG (RAW12 / RAW_SENSOR) stills with strict loadability gates
• Bracket bursts, ZSL/HDR still modes where supported
• Hardware JPEG companion path
• In-app MP4 (H.264/HEVC); HFR via MediaCodec when matrix allows

<b>Preview & HUD</b>
• Portrait engine with professional readout strip and command dial
• Built-in and imported LUT preview (GLES)
• Focus peaking, histogram, horizon level, eye-AF overlay (device-dependent)

<b>FOSS commitment</b>
• Apache-2.0 license
• No proprietary blobs
• No Google Play Services dependencies

Updates: GitHub Releases and Obtainium today. F-Droid submission is in progress using metadata in this repository.
