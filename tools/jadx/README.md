# jadx (local tool, not in git)

APK decompile scripts download [jadx 1.5.1](https://github.com/skylot/jadx/releases/download/v1.5.1/jadx-1.5.1.zip) into this folder on first run:

- `scripts/pns_proshot_apk_decompile.ps1`
- `scripts/pns_motioncam_apk_decompile.ps1`

Or install jadx system-wide and ensure `jadx` / `jadx.bat` is on `PATH`.
