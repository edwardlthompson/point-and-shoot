Camera Parity Leaderboard

Tested Camera2 capability vs OEM marketing — for informed purchases and custom ROM buyers

Methodology

Scores reflect what third-party apps can access via Android Camera2 through Point & Shoot — not what the OEM camera app shows on the box.

  • Parity pts: weighted total = features + resolutions + capabilities (proven 10 pts, matrix-gated skip 8, advertised-only 4; plus gate tiers). Higher absolute score ranks higher — not the same as “number of features confirmed.”
  • Features / Resolutions: catalog cells — proven (10 pts), matrix-gated skip (8), advertised-only (4)
  • Capabilities: per-camera feature gates — advertised + appEnabled + sessionOk
  • Honesty %: proven ÷ HAL-advertised cells
  • Res betrayal: % of rear cameras where spec-sheet / focal-row MP or alternate HAL stream maps exceed the Camera2 default still path by ≥25% (0 = honest; higher = more withholding)
  • Tested API: Android version (SDK/API level) on the device when the parity sweep ran — OEM updates can change Camera2 behavior
  • Sensor sum (mm²): combined physical area of rear cameras — from Camera2 HAL when scanned on-device, otherwise GSMArena published sensor types
  • Restriction Index: OEM composite (lower openness = more gating)

AnTuTu scores are fleet averages from public rankings, not your specific unit.
