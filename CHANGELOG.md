### Added

- **Compose UI integration round (Phase 4 / Phase 2 cross-cut, 5 device-validated screens)** — closes the on-device interactive surface for calibration, LUT management, live-preview HUD, and live About hydration:
  - `CalibrateScreen.kt` — in-app Calibrate flow (chart-photo flavor): target picker (`BundledReferenceTargets.All`), SAF "Load chart photo…" picker, four-corner tap with live overlay (`Canvas` + `pointerInput.detectTapGestures`), Compute → `CalibrationSampler.sample` → `CalibrationMath.computeWbGains` → `CalibrationMath.computeCcm` chain, Save → `CalibrationProfileStorage.save(...)` (atomic write under `getExternalFilesDir(null)/calibration/`).
  - `BitmapRgbPlane.kt` — converts an Android `Bitmap` to a linear-light, normalized `RgbPlane` (sRGB EOTF, long-edge downsample to 1024 px). 11 JUnit tests in `BitmapRgbPlaneTest.kt` cover the EOTF endpoints (0 → 0, 255 → 1, midtone via 2.4 power law, linear segment), monotonicity across all 256 input values, defensive clamping of out-of-range bytes, and the long-edge downsample arithmetic for landscape + portrait + at-cap inputs.
  - `LutImporterScreen.kt` + `ImportedLutStore.kt` — SAF "Import LUT…" picker with `OpenDocument(arrayOf("*/*"))`, validates via `LutImportValidator.validate(bytes)`, atomic-write to `getExternalFilesDir(null)/luts/imported/<safeName>.cube` plus `<safeName>.cube.sha256.txt` sidecar. Filenames sanitized to `[A-Za-z0-9._-]` (capped at 96 chars, leading dots stripped, run-of-underscores collapsed); collisions resolved via `_2`, `_3`, … suffixes with a SHA-derived fallback at 9999. 9 JUnit tests in `ImportedLutStoreTest.kt` cover the sanitize / collision / sha256 helpers.
  - `LutChipRow.kt` — Pro HUD chip row with separate STILL LUT + VIDEO LUT chips backed by an `AlertDialog` picker that lists every `LutCatalog.forScope(scope)` entry with display name, 1-line description, SPDX badge, and a "Reset to None" affordance. Selection persists immediately to `HudSettings`.
  - `HudSettings` extended with `selectedLutForStills` + `selectedLutForVideo` fields (both `LutCatalog.None.name` by default) plus `stillsLut()` / `videoLut()` resolvers that fall back to None on rename or removal. SharedPreferences keys `selected_lut_stills` / `selected_lut_video`. 5 JUnit tests in `HudSettingsLutResolutionTest.kt`.
  - `ProHudScreen` now hosts the LUT chip row between the command dial and record button.
  - `PreviewEngineScreen.LivePreviewHudOverlay` — the live `TextureView` is now wrapped in a `Box` with the FPS / cameraId readouts, the LUT chip row, the command dial, and an `EyeAfOverlay` placeholder riding on top. Honors `HudSettings` toggles.
  - `CameraCapabilitiesProbe` — new `Calibrate` and `Import LUT` home-screen buttons; new `--es pns_screen` aliases (`about` / `prohud` / `hudsettings` / `calibrate` / `lutimport`) for one-line ADB navigation; live `EncoderAttemptJsonAdapter.loadLatest(...)` → `EncoderResultAggregator.summarize(...)` plumb-through to `AboutScreen(liveSummary = …)`.
  - **Device-validated on adb 8bf09993 (OnePlus 13, CPH2655, LineageOS 23 / Android 16)**: home + ProHUD + LUT picker + LUT persistence (force-stop survives) + About live hydration (180 attempts across 4 cameras, top recipes per camera, Cam2 Hfr 480fps measured 427.8 fps) + Calibrate + LutImporter + PreviewEngine with HUD overlay riding on a 59.3 fps Camera2 preview. Screenshots in `docs/screenshots/`.

## Release procedure (reminder)

When tagging a release:

1. Run `.\scripts\pns_verify_toolchain.ps1` (must exit 0).
2. Move all items from **Unreleased** into a new `## <version> - YYYY-MM-DD` section.
3. Annotated git tag, then publish a GitHub Release using `RELEASE_NOTES_TEMPLATE.md`.
4. Add a fresh empty `## Unreleased` section above the new versioned section.
